¿Cómo decide el modelo?
  1. Cada signo recibe un puntaje de 0 (normal) a 3 (alarma): temperatura, frecuencia cardiaca, saturación de oxígeno e intensidad del dolor.
  2. Si el puntaje total es 0, el resultado es NO ENFERMO.
  3. Si hay síntomas desde hace 90 días o más y el puntaje total es 8 o más, el resultado es ENFERMEDAD TERMINAL.
  4. Si hay síntomas desde hace 90 días o más (con puntaje menor a 8), el resultado es ENFERMEDAD CRÓNICA.
  5. Si el puntaje total es 5 o más, o algún signo tiene puntaje 3, el resultado es ENFERMEDAD AGUDA.
  6. En los demás casos, el resultado es ENFERMEDAD LEVE.

También puede consultar el modelo como API REST con POST /predecir. La documentación interactiva está en /apidocs.
